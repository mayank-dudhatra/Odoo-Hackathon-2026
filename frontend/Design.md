Recommended Visual Style
Use white cards on a very light gray page background.
Keep the interface bright, clean and spacious.
Use blue primarily for actions, navigation highlights and important information.
Avoid excessive gradients and decorative colors.

15. Overall Visual Direction
Professional + Modern + Clean + Enterprise + Data-focused + Trustworthy
The entire application should feel like one product, not a collection of independently designed pages.
Golden Rules
Use the same colors everywhere.
Use Inter everywhere.
Use the same spacing scale everywhere.
Use the same border radius everywhere.
Use the same button/input/card styles everywhere.
Use semantic colors consistently.
Prefer clean white surfaces and subtle borders.
Keep blue as the primary brand/action color.
Avoid unnecessary gradients, excessive shadows and random colors.
Every new phase/module must follow this theme.
